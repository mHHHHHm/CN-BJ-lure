# 大肥鱼历险记

北京路亚免费钓点 App。**Android 原生**（Kotlin + Compose + Room），不是网页套壳。

> 只收免费、合法的路亚水域，不收录黑坑和收费钓场。
> 每条钓点都能看到目标鱼种、对应拟饵、出钓窗口，并自动做禁钓区校验；
> 首页还给出**实时天气、估算水温、出钓指数、推荐时段和穿衣建议**。

## 二、功能

### 钓点（首页）

- **按距离排序**：定位或手动选一个出发点，列表按距离从近到远排
- **筛选**：区域 / 鱼种多选 / 5·15·30 公里
- 每条显示：名称、区、水域、距离、鱼种、来源（官方公布 / 民间野钓点 / 管制易变）、坐标可信度
- 落在禁钓区里的点**标红并沉到列表最底部**，不静默隐藏

### 天气与出钓指数（首页顶部）

- 实时天气：温度、体感、天气现象、风速、气压、湿度、今日温区
- **估算水温**：用过去 5 天的气温做指数加权（水体的热惯性大，气温只是间接指标）
- **出钓指数 0-100**：7 个因子加权，每一项都能展开看打分依据
- **推荐时段**：从未来 48 小时里滑动挑出得分最高的三段，带「今天 / 明天」前缀
- **穿衣建议**：按体感温度分 7 档，另加钓鱼场景的提醒（防风、雨衣、涉水鞋、保温杯）

### 饵料（鱼种工具）

- 选鱼种 → 直接给拟饵、克重、水层、操作手法、推荐度
- **装备档位**：微物 / 泛用 / 雷强 / 远投，回答「我这套装备该买哪些饵」
- 可按地形收窄（缓坡 / 石头堆 / 水草区 / 深潭 / 浅滩 / 桥墩结构 / 流水）

### 地图

- 自绘北京区县轮廓 + 禁钓区浅红多边形 + 京密引水渠禁钓段
- 钓点按来源着色，**空心圈 = 坐标只是大致位置**
- 双指缩放、拖动

### 说明

三层水域的法规解释、内置禁钓区清单、数据质量统计、数据来源与局限。

### 坐标可信度是显式标注的

| 等级 | 数量 | 含义 |
|---|---|---|
| `EXACT` | 12 | 坐标已核实（OSM 水体、桥梁、官方点名地标） |

## 四、几个刻意的技术选择

### 1. 禁钓区模型拆开了「禁钓」和「禁渔」

需求文档把「全年禁渔河道」和「饮用水源保护区」并列放进同一张禁钓表，这两件事法律后果完全不同：

> 京政农发〔2019〕63 号：**禁止作业类型：除钓具（不包括河湖延绳钓）之外的所有作业方式。**

也就是说永定河、潮白河、温榆河、清河这些 **179 条全年禁渔河流**，以及密云水库、怀柔水库等
**40 处季节性禁渔水库**，一人一杆一饵一钩照样能钓 —— 禁的是网捕、电毒、多钩延绳。

所以 `ZoneType` 带 `blocksAngling` 标志：只有水源一级保护区、增殖放流水域、公园非钓鱼区才拦人，
禁渔区只给蓝色提示。把两类混在一起会把大量合法钓点标成红色，是往错误的合规判断上带。

### 2. 定位不用 Google Play 服务

文档建议 `play-services-location`。国内大量 Android 设备没有 GMS，`FusedLocationProviderClient`
在这些机器上直接拿不到位置。改用系统原生 `LocationManager`（GPS + 网络定位），哪儿都能用。

### 3. 地图不接高德 SDK，改成自绘

高德 SDK 要申请 API Key 并绑定包名与签名哈希，没配 Key 的地图就是一片空白 ——
而这个工程要保证「clone 下来直接能跑」。这个 App 只需要画「区县轮廓 + 禁钓区色块 + 钓点圆点」，
数据本来就在本地，自绘比引 SDK 更轻，也没有联网依赖。

要换高德只需替换 `ui/map/MapScreen.kt`，其余各层不受影响。

### 4. 出钓指数不抄现成公式，因子逐条立

| 因子 | 满分 | 理由 |
|---|---|---|
| 水温 | 22 | 鱼是变温动物，这是第一因素。用过去 5 天气温指数加权估算 |
| 气压 | 18 | 直接影响溶氧与鱼的泳层 |
| 气压趋势 | 12 | 「气压正在怎么变」比「气压是多少」更关键，骤降天几乎不开口 |
| 风力 | 12 | 1-4 m/s 起涟漪增溶氧又不太影响抛投 |
| 天气 | 10 | 多云和毛毛雨反而好，强对流最差 |
| 季节 | 10 | 北京春秋最好、夏季只能钓早晚、冬季路亚基本停口 |
| 时段 | 16 | 日出前后与日落前是硬窗口 |

外加两条**硬封顶**（限制性因子，不是加分项）：水温 < 8℃ 封 45 分、< 11℃ 封 60 分、
**没到 16℃ 开口线封 82 分（不给「极佳」）**。

### 5. 钓友经验的落地

翻 B 站 / 小红书 / 知乎的华北钓友实战复盘后，把这些结论写进了模型和文案：

- **黑鱼是昼伏夜出的伏击鱼种**，「晚上没口」是错的；但**黄昏到入夜后两小时才是晚口，半夜反而停**
- 路亚目标鱼的黄金开口水温 **15-28℃**（模型取 16-26℃ 为满分区间）
- **华北正常 10 月上中旬收口**，浅水区水温跌破 15℃ 基本可以封竿
- 秋季是打黑狂口期，但**窗口极窄**，没卡上时间就是空军
- 装备分层：黑鱼 / 翘嘴 / 鳜鱼属高预算档，**500 元以内建议马口起步** —— 对应本 App 的「微物」档
- 夜钓提竿节奏：炸水后默数几秒再发力，抢拍就是脱钩 + 惊窝

## 五、怎么构建

工程已经对齐本机 `android-toolchain` 里验证过的组合：**AGP 8.9.2 + Gradle 8.11.1 + JDK 17**。

```powershell
$tc = "D:\deepseek-cache\dsh-workdata\android-toolchain"
$env:JAVA_HOME        = "$tc\jdk"
$env:ANDROID_HOME     = "$tc\sdk"
$env:ANDROID_SDK_ROOT = "$tc\sdk"
$env:GRADLE_USER_HOME = "$tc\gradle-home"    # ★ 必须设，否则中文用户名会导致 native-platform 加载失败
Set-Location <本工程目录>

# 调试包
& "$tc\gradle-8.11.1\bin\gradle.bat" --no-daemon assembleDebug
# 正式包（带签名，R8 混淆 + 资源压缩）
& "$tc\gradle-8.11.1\bin\gradle.bat" --no-daemon assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`

## 六、离线验证

本机没装 Android Studio 也能跑的那部分：

```bash
python verify/run_verify.py        # 用便携 JDK + kotlinc 编译 domain 层并跑 104 项单测
python verify/syntax_check.py      # 对 Android 层做语法体检（无依赖，只看语法）
python verify/validate_assets.py   # 校验种子数据与解析预期一致
```

`run_verify.py` 覆盖：

- 距离计算、多边形判定、多环水体（密云水库那种碎片化水面）
- **禁渔区 ≠ 禁钓区**这条核心规则，以及混合场景下以真禁钓为准
- 季节性禁渔的月份边界（3 月未生效 / 4 月生效 / 9 月生效 / 10 月未生效）
- 列表筛选：免费硬筛选、鱼种/区域/距离筛选、无坐标点的处理、禁钓点沉底
- **出钓指数校准**：深秋冷夜不给「极佳」、理想秋天傍晚 85+、盛夏正午扣分、
  冬季低分、雷暴压低、气压骤降扣分、水温未到开口线封顶 82
- 推荐时段带日期前缀且互不重复、按时间排序
- 穿衣分档与钓鱼场景提醒

## 八、已知限制

- 官方适宜垂钓区名单发布于 2019 年，河段与配套设施可能已变化，出行前请以现场标识为准
- 地图上的禁钓区多边形是**水体形状示意**，不是法定边界；现场有「禁止垂钓」标识时以标识为准
- 民间钓点信息时效性差，鱼情随放水、清淤、施工剧烈变化，**不保证有鱼**
- 出钓指数是基于天气的推算，**不构成鱼情承诺**
- 南水北调干渠明渠段的几何数据未获取到，当前只在文字说明里提及，未做多边形校验
- 天气需要联网；断网时指数区会显示「天气获取失败」，其余功能不受影响
- 本 App 只做信息汇总，不构成法律意见

## 构建与签名

### 环境

- JDK 17
- Android SDK（platform 34 / build-tools 34.0.0 / platform-tools）
- Gradle 8.11.1（或直接用工程里的 wrapper）

### 步骤

1. 在工程根目录建 local.properties，填 SDK 路径：

   `properties
   sdk.dir=/path/to/android-sdk
   `

2. 重新生成地图瓦片（**不入库，必须自己拉一次**，否则地图页是空白的）：

   `ash
   python tools/fetch_tiles.py      # 下载 z7~z10 北京全域瓦片到 assets/tiles/
   python tools/gen_seed.py         # 由 bj-fishing/build.py 生成 assets/seed/*.json
   python tools/make_icons.py       # 生成图标与启动画面
   `

3. 构建：

   `ash
   ./gradlew :app:assembleDebug         # 调试包，不需要签名
   ./gradlew :app:assembleRelease       # 发布包，需要下面的签名配置
   `

### release 签名

**签名口令不存在这个仓库里**，需要自己建 keystore 并在 local.properties 补上：

`properties
RELEASE_STORE_FILE=keystore/your.p12
RELEASE_STORE_PASSWORD=***
RELEASE_KEY_ALIAS=***
RELEASE_KEY_PASSWORD=***
`

没配这四项也能编 —— 只是 release 包不做签名（pp/build.gradle.kts 里做了判断）。

keystore/ 与 local.properties 都在 .gitignore 里，**别改成提交**：
签名私钥泄露意味着别人可以签一个恶意包冒充你发布更新。

### 自检

`ash
python verify/run_verify.py        # 领域层单元测试（104 项）
python verify/syntax_check.py      # 语法体检（剥掉 Android 依赖后编译）
python verify/validate_assets.py   # 种子数据校验
`
